# Satsang Shorts Review

A review board for a year of weekly short videos drawn from Gurudev's Hindi
discourses. Each entry shows the passage, a preview frame of the finished short,
and the source recording with its timestamp.

Reviewers can mark each one Ready / Needs work, retitle it, choose a different
background, and leave a note. Decisions are stored in your own browser — use
**Copy decisions** to send them back.

Single self-contained page, no build step and no tracking.
